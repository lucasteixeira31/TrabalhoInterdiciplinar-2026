# Trabalho Interdisciplinar II - Back-End

Repositório destinado às atividades da disciplina de Trabalho Interdisciplinar II - Back-End.

## Exercício 1
Integração entre Eclipse e GitHub.

## Exercício 2
Integração entre Java e PostgreSQL utilizando JDBC.

O exercício implementa operações CRUD sobre uma tabela de usuários:

- Listar
- Inserir
- Excluir
- Atualizar
- Sair

## Tecnologias utilizadas

- Java
- Eclipse
- Git
- GitHub
- PostgreSQL
- JDBC
- phpPgAdmin
