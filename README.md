# Trabalho Interdisciplinar II — Back-End

Repositório destinado às atividades práticas da disciplina **Trabalho Interdisciplinar II — Back-End**, da PUC Minas.

## Exercícios

### Exercício 1 — Integração Eclipse e GitHub
Desenvolvimento de uma aplicação Java no Eclipse para realizar a soma de dois números inteiros.

### Exercício 2 — Integração PostgreSQL
Desenvolvimento de uma aplicação Java integrada ao PostgreSQL, utilizando JDBC e o padrão DAO para realizar operações CRUD.

### Exercício 3 — Integração Spark
Desenvolvimento de uma aplicação Web utilizando Java, Maven, PostgreSQL, Spark Framework e formulário HTML.

### Exercício 4 — Computação em Nuvem e IA como Serviço
Utilização do Microsoft Azure para criação de um banco PostgreSQL na nuvem e consumo de um serviço cognitivo por meio de uma aplicação Java.

## Tecnologias utilizadas

- Java
- Eclipse
- Git e GitHub
- Maven
- PostgreSQL e JDBC
- Spark Framework
- HTML
- Microsoft Azure
- Azure AI Language

## Organização

Cada exercício está organizado em uma pasta própria, contendo:

- `README.md` — enunciado e requisitos da atividade.
- `Exercício N/` — código-fonte e arquivos do projeto.

O Exercício 4 também contém evidências de execução e configuração dos recursos utilizados na nuvem.
