# Exercício 3 — Integração Spark

**Disciplina:** Trabalho Interdisciplinar II — Back-End  
**Modalidade:** Individual  
**Valor:** 5 pontos

## Objetivo

Desenvolver o back-end de uma aplicação Web em Java, utilizando Eclipse, Maven, PostgreSQL e Spark Framework.

## Problema

Implementar um sistema CRUD semelhante ao desenvolvido no Exercício 2, acrescentando uma interface Web para entrada e apresentação de dados.

O desenvolvimento deverá contemplar:

1. Criar um formulário HTML.
2. Utilizar o formulário para ler e apresentar os dados da aplicação.
3. Implementar a integração entre o formulário HTML e o back-end Java utilizando Spark Framework.
4. Utilizar PostgreSQL para o armazenamento e a manipulação dos dados.

A aplicação deverá seguir como referência os exemplos **WS03 Produto Service** e **WS04 Produto**, relacionados ao cadastro de produtos.

Este exercício representa uma prévia do projeto a ser desenvolvido durante a disciplina.

## Tecnologias

- Java
- Eclipse
- Maven
- PostgreSQL
- Spark Framework
- HTML

## Entrega

Disponibilizar no GitHub o projeto contendo a solução desenvolvida.

A URL do projeto deverá ser informada nos comentários da entrega, acompanhada da nota de autoavaliação do aluno.

A atividade será avaliada considerando:
