# Exercício 1 — Integração Eclipse e GitHub

**Disciplina:** Trabalho Interdisciplinar II — Back-End  
**Modalidade:** Individual  
**Valor:** 5 pontos

## Objetivo

Criar um programa em Java utilizando o ambiente de desenvolvimento Eclipse.

## Problema

Desenvolver uma aplicação Java que realize as seguintes etapas:

1. Criar um novo projeto Java no Eclipse.
2. Criar uma nova classe.
3. Implementar, compilar e executar um programa que some dois números inteiros.

## Entrega

O aluno deverá disponibilizar no GitHub o projeto contendo a solução desenvolvida.

A URL do repositório deverá ser informada nos comentários da entrega, acompanhada da nota de autoavaliação do aluno.

## Avaliação

A atividade será avaliada considerando:

- Clareza e completude do código-fonte.
- Autoavaliação do aluno, utilizada na normalização da nota.
- Artefatos produzidos e interações no GitHub, quando aplicável.
