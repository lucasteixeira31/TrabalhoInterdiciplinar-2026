# Exercício 2 — Integração Eclipse e PostgreSQL

**Disciplina:** Trabalho Interdisciplinar II — Back-End  
**Modalidade:** Individual  
**Valor:** 5 pontos

## Objetivo

Desenvolver um programa em Java utilizando o ambiente Eclipse para manipular dados no sistema gerenciador de banco de dados relacional PostgreSQL.

## Problema

Desenvolver uma aplicação Java que realize as seguintes etapas:

1. Criar uma tabela `X` no PostgreSQL.
2. Criar uma classe `X` em Java, correspondente à tabela.
3. Criar uma classe DAO (*Data Access Object*) para manipular os dados da classe `X`.
4. Criar uma classe `Principal` com um menu contendo as opções:
   - Listar
   - Inserir
   - Excluir
   - Atualizar
   - Sair

As operações do menu devem acessar as funções CRUD implementadas na classe DAO.

## Entrega

O aluno deverá disponibilizar no GitHub o projeto contendo a solução desenvolvida.

A URL do projeto deverá ser informada nos comentários da entrega, acompanhada da nota de autoavaliação do aluno.

## Avaliação

A atividade será avaliada considerando:

- Clareza e completude do código-fonte.
- Autoavaliação do aluno, utilizada na normalização da nota.
- Artefatos produzidos e interações no GitHub, quando aplicável.
