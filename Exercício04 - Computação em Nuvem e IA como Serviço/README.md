# Exercício 4 — Computação em Nuvem e IA como Serviço

**Disciplina:** Trabalho Interdisciplinar II — Back-End  
**Modalidade:** Individual  
**Valor:** 5 pontos

## Objetivo

Conhecer e utilizar recursos de computação em nuvem da plataforma Microsoft Azure, incluindo banco de dados PostgreSQL e serviços de Inteligência Artificial.

## Produto 1 — Ativação da conta Azure

Ativar uma conta no Microsoft Azure utilizando o e-mail acadêmico da PUC Minas (`@sga.pucminas.br`), por meio do programa Azure for Students.

**Não é necessário fornecer cartão de crédito.**

**Entregável:**
- Captura de tela do Portal Azure que identifique o usuário vinculado à conta.

## Produto 2 — Banco de dados PostgreSQL no Azure

Criar e utilizar um banco de dados PostgreSQL hospedado no Microsoft Azure.

**Requisitos:**

1. Criar um recurso PostgreSQL no Azure.
2. Criar uma base de dados e uma tabela de interesse.
3. Inserir registros na tabela.
4. Executar uma consulta SQL `SELECT` para demonstrar os registros armazenados.

**Entregáveis:**

- Captura de tela do recurso criado no Azure, identificando o servidor (URL) e a conta vinculada.
- Captura de tela demonstrando a conexão ativa com o banco de dados e o resultado da consulta `SELECT`.

## Produto 3 — Inteligência Artificial como Serviço

Implementar uma aplicação Java que utilize um modelo de Inteligência Artificial disponibilizado na nuvem.

Escolher uma das alternativas:

### Opção A — Machine Learning

1. Criar e treinar um modelo utilizando uma base de dados.
2. Publicar o modelo na nuvem.
3. Consumir o modelo por meio de chamadas em Java.

O modelo pode ser de classificação, previsão/regressão ou recomendação. Não é exigida alta precisão.

**Entregáveis:**
- Captura do fluxograma do modelo criado no Azure.
- Código Java consumindo o modelo publicado.

### Opção B — Serviços Cognitivos

Criar uma aplicação Java que consuma uma API de serviço cognitivo disponível no Azure.

**Entregáveis:**
- Captura de tela do recurso cognitivo criado no Portal Azure, mostrando seus detalhes.
- Código Java demonstrando o consumo do serviço.
